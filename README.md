# Shreyansh Portfolio v2

A Vercel-ready portfolio built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- Premium dark, tech-forward visual design
- More lively color palette with cyan / blue / violet gradients
- Better animations using Framer Motion and CSS motion effects
- Featured GitHub project cards
- Experience timeline based on real resume content
- Skills map for engineering, infrastructure, security, and operations
- Verified LinkedIn test score entries
- Fully filled ACM publication section
- Resume viewer/download button

## Run locally

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Go to Vercel.
3. Import the repository.
4. Click deploy.
